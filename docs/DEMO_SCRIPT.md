# Three-minute demo path

This is the target recording flow. Items marked **simulation** must not be
presented as live until their adapters are connected and verified.

## 0:00–0:25 — The problem

A human DJ cannot babysit an AI chat window while performing. Show the two
Decks, versioned queue, and authoritative performance revision. Explain that
Meta chooses strategy while deterministic local code owns audio timing.

## 0:25–1:05 — A constrained Meta decision

Show A→B and the preserved B→C path. Point to the exact exit/entry beats,
confidence, reason, model name, queue revision, and validation status. The
model selects from safe candidates; it cannot invent arbitrary cue points.

## 1:05–1:45 — The human changes the set

Extend B past the planned exit. Show the old plan become invalid without
stopping B. The supervisor observes the new real beat and creates a new future
plan without seeking backward.

## 1:45–2:25 — Local execution

Approve and arm the replacement plan. Show lifecycle changes and Mixxx execute
the transition. Explain that scheduling, sync, crossfader, and cleanup are
local—not language-model tool calls.

## 2:25–2:50 — Human takeover

Move the mixer or press Take over. The remaining automation is cancelled and
cleanup is skipped so the software does not fight the performer.

## 2:50–3:00 — Close

Human improvisation changes the future. The AI adapts, but the human retains
control.
