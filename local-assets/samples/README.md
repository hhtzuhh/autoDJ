# Song library

Place MP3, WAV, FLAC, M4A, OGG or AIFF audio here before starting the bridge.
Subfolders are scanned recursively. Private songs are ignored by Git.

Build selects from this library. Matching analyses are read only from this
repository's `artifacts/time-map/`, using the audio SHA-256 identity. No songs
or precomputed analysis ship with this repository.
